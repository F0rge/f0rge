Required Columns Documentation

Inventory List CSV

  • SKU: Unique identifier (Required)
  • Name: Product name (Required)
  • Category: Main category (Required)
  • Retail Price: ZAR including VAT (Required)
  • Cost Price: Landed cost ZAR (Optional)
  • Barcode: EAN/UPC (Optional)

Stock on Hand CSV

  • SKU: Must match Inventory list (Required)
  • Location: e.g., 'Sandton', 'Warehouse' (Required)
  • Qty: Numeric quantity (Required)
  • Unit Cost: ZAR per unit (Optional)
