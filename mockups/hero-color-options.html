Hero Strip — Color Options

Three distinct directions for coloring the hero stats strip. Each shown at desktop (900px) and iPhone (375px).

Option A — Per-tile KPI tint safe

Each tile gets a whisper-thin wash that maps to its category (Overall=indigo-50, Sleep=sky-50, Gut=rose-50 when bad / emerald-50 when clear, Histamine=amber-50, Treatment=violet-50). No gradient. The page background disappears behind colored per-tile surfaces, giving each KPI its own identity without shouting. Readability is highest here — color tints are load-bearing semantics, not decoration.

Option B — Color earns its place ambitious

Tiles are flat white with stone borders — indistinguishable from every other card on the page. Color lives only in the KPI value itself (Overall=indigo-600, Sleep=sky-600, Gut=rose-600 when bad, Histamine=amber-600) and the tiny trend line. Nothing colored is decorative; every colored pixel communicates meaning. The strip reads as a peer of the cards below it, not as a special zone. Most restrained — riskiest if the strip needs more visual presence.

Option C — Traffic-light status tiles bold

Each tile background reflects the current state of that KPI: green tile when the metric is good, amber when watch-worthy, red when concerning, neutral-white when no data. The whole strip is a 5-second health read from across the room. Most data-forward option — but the warm palette from the page background (--bg #fefce8) keeps it from feeling clinical. Tile borders match the fill to reduce visual noise. Values stay black for max legibility over a colored ground.

Baseline — Current gradient (reference only)

The current hero-stats.tsx applies bg-gradient-to-r from-indigo-50 to-amber-50 — a single continuous gradient across the whole strip. All five tiles share one background rectangle that fades lavender → cream → soft yellow left-to-right. Values use semantic text colors (emerald/amber/red) inside the gradient field. There is no tile separation from the background. The complaint: the gradient reads as a flavored background accent rather than purposeful color, and the lavender-to-yellow sweep has no semantic relationship to the KPIs it's washing over.
