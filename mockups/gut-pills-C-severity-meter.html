Mockup C — Severity meter + uniform grid

Recognizes that severity is ordinal (None → Severe is a scale, not a list of arbitrary choices). Bloating + Joint pain become a 4-segment intensity meter where segments fill progressively from left. The current label sits above the meter so it never competes for horizontal space with the choices. Stool stays as a uniform grid because it's categorical.

Wins: severity questions encode rank visually — "filled up to here" reads instantly; no text variance to fight; very compact; the categorical question keeps a familiar pill grid so the user understands the difference between scale-like and choice-like questions.

Trade-offs: biggest behavioral change of the three; meters without labels mid-segment require the user to learn the mapping (mitigated by hover/tap labels and the end-labels under the meter); accessibility needs care (aria-label per segment + aria-valuetext on the meter as a whole).
